DO ✅
   ✅ Keep firebase-credentials.json local only (NOT on GitHub)
   ✅ Use .gitignore to protect secrets (already done)
   ✅ Create strong SECRET_KEY (random string)
   ✅ Verify all environment variables before deploying
   ✅ Test website after deployment
   ✅ Check Render logs if issues occur
   ✅ Push to GitHub to update your live website

DON'T ❌
   ❌ Commit .env to GitHub (it's in .gitignore)
   ❌ Commit firebase-credentials.json (it's in .gitignore)
   ❌ Use weak or obvious secret keys
   ❌ Deploy without environment variables
   ❌ Forget to add Firebase credentials
   ❌ Ignore error logs if something breaks

🆘 IF SOMETHING GOES WRONG:

Problem:              Solution:
═════════════════════════════════════════════════════════════════════════════

Deployment fails      → Check Render logs for error message
                      → Usually missing environment variable
                      → Add variable and retry

Website shows 500     → Check Render logs
error                 → Add missing Firebase credentials
                      → Redeploy

Can't push to         → Verify GitHub login credentials
GitHub                → May need personal access token
                      → Check GitHub documentation

Firebase error        → Verify firebase-credentials.json copied correctly
                      → Ensure Firebase project is active
                      → Check Firestore is enabled

Email not sending     → Verify Gmail 2FA is enabled
                      → Use App Password (not Gmail password)
                      → Check MAIL_* variables in Render
