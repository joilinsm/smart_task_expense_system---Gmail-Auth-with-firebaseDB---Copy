🔐 ENVIRONMENT VARIABLES NEEDED
════════════════════════════════════════════════════════════════

From firebase-credentials.json:
  • FIREBASE_TYPE = "service_account"
  • FIREBASE_PROJECT_ID = "your-project-id"
  • FIREBASE_PRIVATE_KEY_ID = "your-key-id"
  • FIREBASE_PRIVATE_KEY = "your-key (with \n)"
  • FIREBASE_CLIENT_EMAIL = "your-email@account.iam.gserviceaccount.com"
  • FIREBASE_CLIENT_ID = "your-client-id"
  • FIREBASE_AUTH_URI = "https://accounts.google.com/o/oauth2/auth"
  • FIREBASE_TOKEN_URI = "https://oauth2.googleapis.com/token"

From your .env:
  • SECRET_KEY = "random-secret-string"
  • FLASK_ENV = "production"
  • DEBUG = "False"
  • FIREBASE_ENABLED = "True"

Optional (for email):
  • MAIL_SERVER = "smtp.gmail.com"
  • MAIL_PORT = "587"
  • MAIL_USE_TLS = "True"
  • MAIL_USERNAME = "your-email@gmail.com"
  • MAIL_PASSWORD = "gmail-app-password"

❓ TROUBLESHOOTING
════════════════════════════════════════════════════════════════

PROBLEM: Deployment fails
SOLUTION: Check Render logs → Usually missing environment variable

PROBLEM: Website shows 500 error
SOLUTION: Add Firebase credentials to environment variables

PROBLEM: Can't push to GitHub
SOLUTION: Create personal access token on GitHub.com/settings/tokens

PROBLEM: Email not sending
SOLUTION: Use Gmail App Password, verify MAIL_* variables
